# A second opinion reruns under a derived id, and a dissent renders

## The prior

A verdict is a claim until a second opinion runs against the same
artifacts. The review is a fresh run over the sealed record. When a
review was refused because the id was already taken, the refusal
derived the convention: a rerun takes the next free id in the family,
the base name then -2 and -3, and the sealed first record never
changes. The latest generation carries the standing verdict. Earlier
generations stay byte-identical, sha-proven.

## Why this holds

The refusal was the design. A second run under one id would have
rewritten a sealed record, and an append-only ledger exists so no
outcome is reshaped after the fact. Deriving the id preserves the first
opinion and still delivers the second. Attempts to argue from absence
failed: a missing review is not agreement. Only a present disagreement
renders: both sides named, and the review's verdict word read from its
record's status line.

## How to apply

- Request the review over the same artifacts, not a conversation.
- A taken id derives the next free id in the family. The sealed record never rewrites.
- The latest generation is the standing verdict. Earlier ones stay byte-identical.
- A dissent renders only when both sides exist.
- The review's verdict word comes from the record's status line.
- Agreement stays quiet: a missing review is not agreement.
- A dissent adjusts the rollup only where the sealed rule allows. A contradicted loss stays a loss.
