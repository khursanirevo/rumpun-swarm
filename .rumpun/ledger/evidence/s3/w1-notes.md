Two agents in the same collab group hand work through `RUMPUN_LANE_FILE` by appending JSON events, never by editing or rewriting. The producer reads the lane, does its piece, and appends `{"from": "w1", "kind": "handoff", "task": "...", "status": "open"}`; the consumer reads the lane, picks an open handoff, appends `{"from": "w2", "kind": "claim", "ref": <that seq>}`, does the work, then appends `{"kind": "done", "ref": <seq>}` with the result. Reading is lock-free and safe for polling because writers append whole lines. The race sits inside `append_event`: it counts existing lines to pick the next `seq` and then writes, so two agents appending in the same instant would pick the same `seq` and interleave their writes. The exclusive `flock` on `RUMPUN_LANE_LOCK` turns count-then-write into a critical section: the second appender blocks until the first unlocks, so every event gets a distinct, gap-free `seq` and each line lands intact.
